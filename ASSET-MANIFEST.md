No portrait or `id.png` is required. SVGs use inline shapes and text only, without external image, script, stylesheet, or font dependencies. Main README image references use relative paths and `?v=1`. Hero artwork includes subtle SVG SMIL pulse effects on abstract geometry. Some GitHub or SVG renderers may show a static frame; text remains readable without motion. The interests artwork is a static three-panel focus summary rather than a cycling carousel, to keep all key information visible in renderers with limited animation support.
